# Preserved school recovery and earned progression

This is an acceptance plan, not a record of play. Inspected baseline: `f4ba55eb66d5bd1171be64d170a6d4753d8a033d`. Name any final test successor or integrated source separately. WORLD owns the stage/package; Integration owns the existing Astra operator. No new worker, competing stage, local heavy build, credential, spend or production toggle is requested. See [source audit](school-earned-progression-source-audit.json).

The original school attempt is paused at its third checkpoint with score zero and assessment pending. Recovery cannot turn that score into a pass: normal completion requires at least 70. After normal failed completion, the actual UI offers **Practise again**. That fresh ordinary attempt must earn its pass through real controls. **Claim free starter permission** allocates no car; it does not complete rental or mapped delivery.

## Prerequisites

- Existing independent Astra review of the trusted/default-OFF host composition and real-host tests, plus exact successor compiler, build, unchanged download budgets, smoke and source manifest. Prior `1b225b90` checks do not automatically cover changed host code.
- WORLD actually receives and verifies a frozen compatible-OFF recovery package and rollback pin, including archive, manifest, Worker and assets hashes. Its reader/writer must preserve v2 with issuance OFF. C1/eec are incompatible rollback targets after v2. Do not issue v2 on the original store before a compatible recovery artifact exists. Paths and reported hashes alone are not delivery.
- One bounded original-store stage window through the existing owner helper and its actual lease/deadline. Bind existing actors A/B; retain raw snapshots locally and publish only sanitized hashes/comparisons. Preserve all controls, saves and unrelated processes. Astra uses only its owned tab.
- Node must pass trusted constructor `reverseGearIssuance: true`; an environment value alone does not activate it. Worker requires exact host binding string `1`. Review any required owner-helper change and check the actual capability reply. Player requests and saved fields cannot enable issuance.
