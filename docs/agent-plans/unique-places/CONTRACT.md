# Unique places: shared contract

Every agent working on this programme follows this file. Read [PLAN.md](PLAN.md) for why. Changes to this contract are made only by
the coordinating session.

## Layout (all new work lives under `scripts/places/`, separate from `scripts/scene-factory/`)

```
scripts/places/
  data/venues.json            # index of every non-home venue (generated by collect.ts from scene-factory briefs + authored venues)
  data/facts/<city>.json      # machine-collected facts per venue (OSM / Wikidata), keyed by venueId
  briefs/<city>.json          # PlaceBriefV1 per venue + CityStyleV1 for the city (research output; hand-checked)
  blender/lib/                # shared bpy library (geometry, materials, LOD, export, render)
  blender/archetypes/<id>.py  # one module per archetype, exposing build(brief, style, rng, detail) -> list[bpy objects]
  blender/worker.py           # long-running headless worker: reads a JSONL job file, builds + exports each job, writes reports
  atlas/                      # global trim-sheet atlas source + build script (CC0 inputs, licences recorded)
  out/                        # GITIGNORED: raw/packed GLBs, renders, reports
  manifest/<city>.json        # committed: venueId -> {lod0,lod1,lod2: {sha256, bytes, triangles}}, archetype, brief digest
```

## CityStyleV1 (one per city, in `briefs/<city>.json` under `style`)

```json
{
  "schema": "allworld-city-style", "version": 1, "city": "abuja",
  "climate": "savanna|rainforest|sahel|desert|temperate|mediterranean|tropical-maritime|highland|cold",
  "vernacular": "short text: what ordinary buildings here look like",
  "wallColours": ["#hex", "..."],         // 4-8 common facade colours actually seen in this city
  "roofColours": ["#hex", "..."],         // 2-6
  "wallMaterials": ["render", "concrete", "..."],   // from MATERIALS, most common first
  "roofMaterials": ["metal-sheet", "..."],          // from ROOF_MATERIALS
  "ground": "laterite|asphalt|paving|grass|sand|cobble|snow",
  "vegetation": ["palm", "broadleaf", "acacia", "conifer", "none"],
  "ornament": "short text: recurring motifs (e.g. Arewa geometric relief, Yoruba carved posts, Georgian sash windows)",
  "sources": [{"url": "...", "what": "..."}]
}
```

## PlaceBriefV1 (one per venue, in `briefs/<city>.json` under `places[venueId]`)

```json
{
  "venueId": "airport", "city": "abuja", "name": "Nnamdi Azikiwe International Airport",
  "archetype": "airport-terminal",
  "subject": "what the model shows, one line (e.g. 'the 2018 international terminal seen from the forecourt')",
  "form": {
    "footprint": "rect|L|U|T|H|ring|oval|round|cross|irregular",
    "width_m": 180, "depth_m": 60,        // main mass, best estimate, real metres
    "storeys": 3, "height_m": 22,         // main mass; height_m is to roof top excluding spires/towers
    "roof": "flat|gable|hip|shed|barrel|dome|multi-dome|tensile|sawtooth|pyramidal|mansard|stepped|curved|wave|none",
    "variant": "optional free text sub-type for the generator (e.g. pier, regional, twin-tower); generators must not require it",
    "wings": 2                            // optional: count of secondary masses
  },
  "facade": {
    "material": "<one of MATERIALS>", "accent": "<one of MATERIALS or null>",
    "colours": ["#hex main", "#hex accent", "#hex trim"],
    "roofColour": "#hex", "roofMaterial": "<one of ROOF_MATERIALS, optional>",
    "windows": "curtain|ribbon|punched|arched|pointed-arch|screen|louvre|none",
    "windowRatio": 0.6                    // 0..1 share of facade that is glazing/openings
  },
  "features": [ {"id": "<one of FEATURES>", "count": 1, "note": "optional detail"} ],
  "setting": { "ground": "...", "trees": "palm|broadleaf|acacia|conifer|none", "forecourt": "parking|plaza|garden|road|water|none" },
  "style": "<one of STYLES>", "era": "1970s",
  "confidence": "high|medium|low",        // high = sources describe the actual building; low = typed guess from city style
  "sources": [{"url": "...", "what": "photo description / fact used"}],
  "notes": "anything the generator author should know (what makes this place recognisable)"
}
```

Rules:
- Never invent a name or a fact. If the building is not described anywhere, set `confidence: "low"` and derive form from the
  city style and the place type; `notes` says so. The 112 "(game venue)" placeholders always get `low`.
- Colours and forms describe the real place as seen in public photos (describe, never copy images into the repo).
- No logos, brand marks or legible names. Signage features are blank boards in brand-neutral colours.
- `archetype` is chosen from what the place actually is, not from the game `kind` (a `walk` venue may be a museum, beach, theatre…).

## Generator interface (Python, Blender 5.2, headless)

```python
# scripts/places/blender/archetypes/<id>.py
def build(brief: dict, style: dict, rng: random.Random, detail: int) -> list:  # detail 0 = LOD0, 1 = LOD1, 2 = LOD2
    ...  # return mesh objects; metres, +Z up in Blender (exported +Y up), ground at z=0, main facade faces -Y (towards camera)
```

- `rng` is seeded from `sha256(city + '/' + venueId)` and is the only randomness source. The same inputs give the same bytes.
- Real dimensions come from the brief, clamped to fit the venue scene: largest horizontal size ≤ 120 m at LOD0; bigger places are
  shown as their recognisable portion (`subject` says which).
- Triangle budgets: LOD0 ≤ 20,000; LOD1 ≤ 4,000; LOD2 ≤ 500. The worker rejects anything over.
- Materials: the lib exposes `lib.mat(slot)` for the global trim atlas (UV-mapped slots: wall finishes, glazing, roof, trims,
  ground) and colours via vertex colour `COLOR_0` (`lib.tint(obj, '#hex')`). No other images. LOD2 uses vertex colour only.
- No lights, cameras, extras, empties or animation in exports.
- Models carry NO baseColorTexture: the game binds the global `scripts/places/atlas/trim.webp` to material "trim" using `atlas/slots.json`.
  Packing uses gltfpack with `-kv` so the UVs of the texture-less material survive.
- Each model has a building object and an optional `-site` object (ground, trees, cars). The silhouette mask uses the building only;
  the 120 m clamp applies to building and site together. `form.width_m/depth_m` describe the main mass only.

## Output and acceptance per model

The worker writes `out/<city>/<venueId>.lod{0,1,2}.glb` (gltfpack meshopt + quantised) and `out/<city>/<venueId>.json`
(triangles, bytes, brotli bytes, bounds, archetype, brief digest, warnings), plus `out/<city>/<venueId>.png` (front 3/4 render) and
a silhouette mask for the distinctness gate. Gates: budgets above; brotli LOD0 ≤ 110 KB, LOD1 ≤ 30 KB, LOD2 ≤ 6 KB; bounds sane;
distinctness: within an archetype, no two places' silhouette masks may have IoU > 0.92 with palette distance < 0.1.
