# Pinned authored hair exports

These are standalone hair accessory GLBs generated by the stdlib-only converter at `../../authored-clothing/export.py`:

```sh
python3 evidence/graphics-loop/authored-complete-body-v1/authored-clothing/export.py --asset short02
python3 evidence/graphics-loop/authored-complete-body-v1/authored-clothing/export.py --asset afro01
python3 evidence/graphics-loop/authored-complete-body-v1/authored-hair/out/test_hair_export.py
```

Each GLB keeps the source OBJ topology/UVs, carries `_MH_SOURCE_VERTEX`, `_MH_ANCHOR_VERTICES`, and `_MH_ANCHOR_BARYCENTRICS` source mapping attributes, transfers the pinned 52-bone weights through MHCLO anchors, and includes the `bodyFeminine` / `bodyMasculine` mapped target deltas. It has a PNG base-color texture with the authored alpha channel and a double-sided `BLEND` material. It contains no duplicate rig; bind it to the actor skeleton using `meshes[0].extras.jointNames` for the joint index order. No body faces are hidden because neither MHCLO has a `delete_verts` section.

## Exact hair source and texture proof

Both OBJ, MHCLO, and MHMAT files come from `s20220526/makehuman-assets@8cf9645b975a98eea056b140df11a1d278da0d10`, whose pinned `hair-pin.json` records per-file SHA-256/length and CC0 evidence. Each material explicitly names its diffuse PNG and says `transparent True`. The PNG Git LFS pointer at that same repository commit is 132 bytes; its SHA and LFS OID/size are recorded in each generated metadata JSON. The downloaded PNG is fetched from the official MakeHuman 1.1 individual-asset mirror and verified against the pointer SHA-256 and exact byte size. Both are 2048×2048, 8-bit RGBA PNGs. No other texture, LFS object, archive, or large asset pack was fetched.

The exporter checks every source file hash/length, checks the LFS pointer content before accepting each texture, and refuses files over 5,000,000 bytes. Its temporary cache is outside the workspace under `/tmp/joinallworld-authored-clothing-cache`. MHMAT's legacy AGPL/GPL headers are handled through the pinned repository's CC0 release README and per-file notices, as documented in `../../authored-clothing/README.md` and `../../clothing-research.md`.

## Mobile texture variants

The original full-resolution GLBs remain available. For the prototype's transfer budget, `short02-mobile.glb` and `afro01-mobile.glb` replace only the last embedded diffuse image buffer view. `mobile-hair.py` uses the bundled Pillow runtime, premultiplied-alpha Lanczos resizing, tries optimized 1024×1024 PNG first, then 512×512 if the PNG would exceed 500 KB. Both 1024px files exceed that threshold, so both outputs use 512×512 RGBA textures. Their GLB materials retain `alphaMode: BLEND` and `doubleSided: true`.

To reproduce with the bundled Python runtime, run `python3 evidence/graphics-loop/authored-complete-body-v1/authored-hair/out/mobile-hair.py`; it verifies exact input GLB and original texture hashes before rewriting, preserves all bytes before the image view, compares mesh/accessor declarations, and writes `mobile-hair-report.json`. Then run `python3 evidence/graphics-loop/authored-complete-body-v1/authored-hair/out/test_mobile_hair.py`. The input exports remain unchanged.
