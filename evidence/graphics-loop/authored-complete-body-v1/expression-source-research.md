# Exact facial expression source for the hm08 actor

## Finding

The official MakeHuman `faceunits01` targets can be transferred onto this actor without nearest-point fitting or guessed topology. A bounded reconstruction of the exact pinned hm08 OBJ reproduces all four meshes in `parametric-base-expressive.glb` in the same ordered vertex/UV split. The remaining sub-micrometer position and UV differences are float32 serialization noise. The official bilateral blink targets close the measured eye aperture, and the official `jawOpen` target contains matching deltas for the body, lower teeth, and tongue.

This establishes an evidence-backed source route for a later adapter. No runtime, rig, exporter, or presentation code was changed by this research.

## Pinned sources and licensing

- Actor: [`parametric-base-expressive.glb`](../authored-character-spike-v1/parametric-base-expressive.glb), SHA-256 `0152129ce2c6022911747f9d7a6df3fdb72a9e6e1bea73db414da1cb8f483077`.
- Base mesh and group metadata: [`nirholas/three.ws` at `ec8d1d270b93b8e2e87e8a6160bb908665fe1fcd`](https://github.com/nirholas/three.ws/tree/ec8d1d270b93b8e2e87e8a6160bb908665fe1fcd). The exact `base.obj` is 1,749,303 bytes, SHA-256 `8e761e6624b8f54536409135d1636da63b32486a90d4897f84e121d144f6fb4c`. The pinned source builder assembles the actor directly from this OBJ, preserving source vertex IDs while splitting vertices on UV seams and scaling positions/morph deltas by 0.1.
- Facial units: [`makehumancommunity/extra-targets` at `7eaba3453134385bb5ea9811ef0b33b85b4b556d`](https://github.com/makehumancommunity/extra-targets/tree/7eaba3453134385bb5ea9811ef0b33b85b4b556d). Its root license is CC0 1.0 Universal; the exact `faceunits01` pack metadata also declares CC0 for the selected targets. Its README describes the pack as autogenerated ARKit facial units. The official [MPFB release notes](https://static.makehumancommunity.org/mpfb/releases/release_2016.html) document importing the pack as shape keys.
- MPFB implementation: [`makehumancommunity/mpfb2` at `d0a32e57a7f915cb2f2b95410e2117648c7bbb7e`](https://github.com/makehumancommunity/mpfb2/tree/d0a32e57a7f915cb2f2b95410e2117648c7bbb7e). `FaceService.load_targets` applies targets as shape keys; `FaceService.interpolate_targets` uses MHCLO barycentric mappings to transfer shape keys to child meshes. The official export-copy operator and docs expose loading/interpolating facial units during copy export.

Each downloaded source file is checked against an exact byte count and SHA-256 by [`expression-source-check.mjs`](./expression-source-check.mjs). The full pin inventory and numeric results are in [`expression-source-check-report.json`](./expression-source-check-report.json); bounded raw inputs are retained in [`expression-source-inputs`](./expression-source-inputs/).

## Exact mapping proof

The diagnostic reconstructs the pinned OBJ groups with the same ordered `(source vertex, UV index)` split and coordinate transform as the source actor builder, then compares the reconstruction with decoded GLB mesh attributes. It also checks source target rows by their explicit original vertex IDs, expands each matched row to every UV-seam duplicate, and applies the same 0.1 target scale as the actor build.

| Mesh | Output vertices | Source IDs represented | Maximum position error | Maximum UV error |
| --- | ---: | ---: | ---: | ---: |
| Body | 14,517 | 13,380 | 0.000000060 m | 0.000000030 |
| Eyes | 160 | 144 | 0.000000057 m | 0.000000030 |
| Teeth | 136 | 136 | 0.000000058 m | 0.000000029 |
| Tongue | 253 | 226 | 0.000000059 m | 0.000000030 |

All four mesh mappings are ordered-exact, including their UV-seam duplicates. Thus sparse target rows can be mapped to the actor directly by original vertex ID; no geometric search is needed.

## Target results

The pinned CC0 targets are small: `eyeBlinkLeft.target` 16,277 bytes, `eyeBlinkRight.target` 16,075 bytes, `jawOpen.target` 51,426 bytes, and `mouthClose.target` 38,826 bytes. Each file and the CC0 license/pack metadata has a checked SHA-256 recorded in the JSON report.

The bilateral blink targets each map 718 sparse rows to the body (747 split output vertices affected), with a maximum displacement of 12.613 mm and mean per-row displacement of 2.894 mm. The reconstructed left/right mean lid aperture is 4.746 mm neutral and -0.161 mm with the corresponding blink target at weight 1; bilateral blink gives -0.161 mm on both sides. This is a measured near-closure with slight lid overlap, not an extrapolation of the actor's weak custom eyelid targets.

Each blink file has another 65 sparse rows outside the four imported meshes. They do not map to the actor's separate `Eyes` geometry, which has zero matching rows. This matters if the omitted source geometry represents lashes or other helpers, but the body lid closure itself is fully represented by the 718 matched rows on each side.

`jawOpen` maps every one of its 2,543 rows into the imported meshes: 2,249 body rows, all 68 lower-teeth rows, and all 226 tongue rows. Maximum displacements are 38.738 mm on the body, 31.408 mm on lower teeth, and 28.144 mm on tongue. No row is missing. The target does not move the upper teeth or eyeballs. `mouthClose` maps all 1,972 rows to the body and has no helper-mesh deltas.

## Diagnostic command and limits

Run `node expression-source-check.mjs` from this directory. It completes in about seven seconds and writes the JSON report. It is a source-mapping/aperture diagnostic, not a rendered visual acceptance test. Before adoption, the runtime needs to add shape targets to the relevant skinned meshes and verify how the target's authored blink combines with the current family/head morphs and eye placement in a render. For jaw animation, apply the same named `jawOpen` weight to Body, lower Teeth, and Tongue; it is a coherent authored target across those meshes. Keep mouth-close/blink combinations bounded to `[0,1]` unless a separate measured test justifies another range.
