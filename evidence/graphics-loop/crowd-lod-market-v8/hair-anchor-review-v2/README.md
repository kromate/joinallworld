# Isolated hair-anchor A/B, v2

This fixture isolates two geometry-placement defects seen in the frozen floor-v5 frames: the male Afro ball overlaps the authored Head bounding box by about 20 cm and masks the face; the female bun has only about 1.6 cm of vertical Head-bounds overlap and appears detached. The measurements are from the original shipped GLBs and are recorded in `hair-anchor-review-v1/head-bone-witness.json`. They are rest-space bounds, not triangle-intersection proof.

The candidate module changes only the generated Afro and bun center Y values. Hair dimensions, center X/Z, tint, saved style, Head-bone skin weights, face, expression, body geometry, and wardrobe generator logic remain unchanged. `Hair anchor` reloads the same saved actor and seed with either the original or candidate placement. The viewer then compares original and compact body geometry using that same loaded actor. It records actual deformed Head-influenced body vertices, source scalp-color vertices, generated hairstyle item vertices/triangles, exact hashes for generated hair color/skin-index/skin-weight/UV attributes, nearest hair-to-Head-vertex distances, and ray tests from camera to body triangles sampled inside the production eye-UV windows. Expensive vertex/raycast diagnostics run only at a settled capture checkpoint, not on every live-walk telemetry tick. The proximity and UV-ray fields are diagnostics; they do not prove continuous surface contact or pixel-level visibility.

The remote GPU recipe pins two saved actors: `graphics-host-crowd-02` (man/Afro/hoodie) and `graphics-host-crowd-03` (woman/bun/owambe). Each hair mode runs a real production walk for at least one 2.4-second cycle, then resets to the same exact phase. The 16-frame matrix compares source/compact body geometry at front and side yaw for source/candidate hair placement. It freezes the original source-mode camera and reuses that exact camera for candidate mode so the silhouette and face visibility can be compared without camera refitting. Candidate bounds must remain inside the frame. No timed interaction, full outfit inventory, mobile performance, or production acceptance is claimed.

Production `src/scene/wardrobe/geometry.ts` is not modified. The isolated package builder aliases only the renderer's geometry module to `geometry-hair-anchor-v2.ts` and pins both files, the viewer, exact import closure, saved inventory, package lock, and source body assets. The separate GPU snapshot pins the CDP controller, capture contracts, package verifier, and artifact pin. Both workflow files are branch-bound templates; no workflow was published or executed by this task. GPU capture is also unrun. Root should review the source/closure and run the bounded package and GPU recipe before interpreting any pixels.
