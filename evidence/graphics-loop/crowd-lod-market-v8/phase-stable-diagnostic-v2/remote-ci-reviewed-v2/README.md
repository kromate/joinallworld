# Phase-stable v8 contact and load-trace diagnostic CPU package, v2

This separate package copies the phase-stable production A/B viewer. It preserves the exact RAF-applied walk phase and records a per-load generation trace. The fixture applies the production foot solver against a visible, non-occluding y=0 support reference after idle and walk sampling, then records pre-solve sole samples, post-solve sole samples, and deformed world-space body/wardrobe minimum and maximum. The support is explicitly the fixture parent-frame plane, not proof of any venue floor.

The camera check is named `boundsInFrustum`: it tests deformed body/wardrobe bounds against the camera frustum, not pixel occlusion. Screenshots include the whole canvas; visual review is still required to determine whether the feet are visible and aligned.

The CPU recipe pins the v2 entry, HTML, saved Market inventory, both source GLBs, complete production import closure, locked dependencies, package builder and runner. It does not modify the v1 fixture or production sources. Package output is diagnostic only, not visual, runtime or mobile acceptance.
