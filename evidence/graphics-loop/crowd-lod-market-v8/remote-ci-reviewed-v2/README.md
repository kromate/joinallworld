This recipe starts from `viewer-market-gpu-v8.ts` and walks the local runtime import graph, resolving `/src/`, relative, `?raw`, and `?url` paths. It also pins direct type-only imports from each runtime-reachable module. `verify-import-closure.mjs` checks the discovered graph against the frozen closure, source hashes and byte counts, and requires every path to be tracked in the checked-out Git commit. This catches a dirty-worktree-only source dependency before esbuild. Bare package imports remain covered by the exact `package-lock.json`.

The new package builder is a separate copy under this folder. It keeps the frozen v8 entry, HTML, assets, and renderer intact, adds explicit guards for the complete local closure, and emits into `static-fixture-market-gpu-v8-v2/`. The Linux runner preserves Node96, 220 MiB process-group RSS, and 25 seconds, with per-process/group peaks, cleanup verification, before/after source hashes, and a package artifact digest. The workflow template is manual-dispatch plus a push only to `codex/graphics-market-lod-v8-cpu-review-v2`; it is not installed.

The closure contains 22 runtime-reachable local files and 2 direct type-only files at preparation time. In the preparation checkout, five closure paths are untracked by its current local HEAD: the v8 viewer, `src/scene/avatar-look.ts`, `src/scene/body/animation-pose.ts`, `src/scene/body/face-shader.ts`, and `src/scene/body/shared-resource-cache.ts`. The verifier checks the actual checked-out commit at run time and rejects any missing/untracked dependency; the local status list is not used as a substitute for checking the published package commit. Root must publish a source commit containing the complete closure before running v2. No package build or browser run is included here.
