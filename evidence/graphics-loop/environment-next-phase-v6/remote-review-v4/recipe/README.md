# V6 bounded remote scene review recipe (prepared, unrun)

This recipe consumes one exact successful v6 diagnostic package artifact and checks its source pins, compile/finalizer receipts, imported-output closure, all 40 city chunks and every delivered file before opening the actual-host fixture. It is a remote scene diagnostic only; package bytes are not release-size or mobile acceptance evidence.

The push-triggered workflow is pinned to package workflow run 37899632982 and source commit 03986c2a778e6e191bec905a493de251c45baa11. It downloads `environment-whole-slice-v6-package-v2-<run-id>`, then validates that artifact name, `source-pins-v6.json` commit, and the reviewer-selected commit all agree. The recipe pins the full package source/public inventory and staged review controller; it rehashes those inputs before and after each job.

Three bounded jobs run with `max-parallel: 3`. `scene-pair-home-neighbourhood` records Home/day, Home/night, Neighbourhood/day, and Neighbourhood/night. `scene-pair-market-beach` records Market/day, Market/night, Beach/day, and Beach/night. `lifecycle-only` anchors at Market/day and records canonical readiness, a durable ordinary walk request/observation, a structured dispose/rebuild, and permanent disposal. Together the two pairs cover all four scenes in both lighting states; lifecycle is a separate job and cannot substitute for a scene capture.

Each job is capped at 2 GiB owned-process-group RSS, Node 96 MiB old space, and 60 seconds. The controller saves each PNG and immediately fsyncs its matching JSONL SHA-256 receipt. The supervisor derives partial counts from newline-complete receipts after exit or timeout, so killed jobs retain an accurate count. A fail-closed readiness or Home canonical-body failure stops the current pair; fallback or unknown body state cannot pass Home review. The static synthetic fixture is not a full onboarding journey, and SwiftShader screenshots, RAF/resource counters, and renderer counts are not physical phone, GPU-time, battery, or quality certification.

Tiny readiness, scope, artifact-selection, result-directory, invocation, and partial-receipt checks pass. No build, workflow, server, or browser run has been performed for this recipe. Before publication, regenerate `review-sources-v4.json` after any source change, review the workflow/branch path, and include all new files in the package source seal. The remote runner is Linux-only and refuses other platforms or branches.
