# NPC startup gate remote diagnostic v1

This is an isolated actual-host diagnostic of the locally reviewed `venue-world.ts` NPC startup retry and its pure startup gate helper. It compiles the current production source tree and the deterministic v7 actual-host viewer, with the viewer's **Production runtime + startup fix** variant selected by default. The v7 production readiness and current-body checks remain active; the target capture additionally requires a current canonical ticket, canonical player, twelve canonical public crowd actors, zero procedural/loading public actors, counters, and complete authored-person canonical counts where the scene reports them. Failed readiness is durably recorded and blocks the screenshot call.

The six remote scopes are Market and Beach, each tested with one of three independent CDP screenshot methods: full surface (`fromSurface:true`), viewport (`fromSurface:false`), and exact canvas-rectangle clip (`fromSurface:true`). Each fresh browser process first records a canonical Home control using the same screenshot method, then transitions into one target, records and validates readiness/layout/canvas/two-RAF/render-counter evidence, records compositor screencast frame timestamps, and makes exactly one target screenshot request. A screenshot timeout remains a failed capture with its CDP request ID and elapsed duration; the controller does not retry by another method. If target readiness, screenshot transport, or PNG validation fails, it still attempts the peer-venue transition and records whether that independent transition settles. Stage, readiness, transition, and capture durations use monotonic times relative to controller start; wall-clock timestamps are retained only as labels. Capture attempt records are fsynced when the CDP response arrives, before PNG validation, so malformed image data still has durable response timing.

The CPU recipe carries the existing remote-only limits: 384 MiB owned process group, Node 96 MiB old space, 25 seconds total CPU package pipeline. Render scopes remain 2 GiB owned process group, Node 96 MiB old space, 60 seconds, and at most three parallel scopes. This is a Linux headless Chrome/ANGLE SwiftShader capture diagnostic, not phone/GPU timing or production download certification. The local helper receipt is only source provenance; browser acceptance is pending.
