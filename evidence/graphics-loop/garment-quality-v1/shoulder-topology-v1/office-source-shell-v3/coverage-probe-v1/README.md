# Office source-shell coverage audit (prepared, unrun)

This isolated fixture checks whether the current production body mask removes any original source-face area that the v5 zero-ease office source shell does not cover. It uses actual male and female shipped GLBs, replays the pinned current smile appearance, and records exact source-index and current-appearance attribute hashes. It does not edit the production body, mask, wardrobe, shader, or fixture.

The audit verifies the body's active post-mask index is exactly the expected whole-triangle subset of the restored full source index. It independently replays the production all-corners bone-region/Y mask predicate using `buildWardrobeGeometry()`'s actual `hides` and `coverage` data. For each emitted shell triangle, it maps rendered chart vertices back to its original source face in barycentric coordinates, checks every fragment corner against source-face simplex bounds and every clipping halfspace, and checks pairwise 2D triangle intersections within each source face. Only after proving all fragment vertices are inside the convex clipped domain and fragments are pairwise disjoint does it compare summed fragment area with an independent sequential clipping calculation using the same neck/hem/wrist halfspaces. It reports maximum pair overlap, maximum outside-plane distance, maximum source-domain violation, the largest uncovered portions among masked source faces, partitions residual area by the first clip plane that excludes it, and separately reports shell overlap with retained body-face area. A source face's emitted triangles carry the original full-source face ordinal; the test fails closed if any mapping or compacted mask subsequence is inconsistent.

The specific source hypothesis is a rest-space mismatch between the production office torso/hips coverage ceiling (`neck.y + 0.013`) and the source shell's open neck cut (`neck.y - 0.018`), a 31 mm Y interval. This is a predicted interval, not an already measured missing-area result. The mask removes whole triangles only when every corner passes the bone-region and Y-coverage tests; shell clipping is geometric per-face clipping. Equal hidden/displayed triangle counts cannot prove their surface regions agree. `coverage.test.ts` includes edge-only contact and duplicate-partial-fragment cases: the latter has a plausible aggregate area sum despite overlapping fragments, so it must fail the pairwise intersection test.

The diagnostic viewer loads and renders matched source/chart actors so its actual appearance and wardrobe paths are exercised, but the remote controller captures **no screenshots**. It uploads a JSON result with per-family hashes, face IDs, barycentric coverage/residual areas, shader/errors, and source-stability receipts. Rest-space coverage does not establish visual quality or all animated poses. The diagnostic's output must be reviewed before proposing any complementary body-face residual or collar/neck adjustment. Do not broaden the mask or move a neckline plane from this result alone.

`remote-ci-v1/` is a branch-push-only Linux harness copied from the previously reviewed bounded GPU diagnostic recipe. Its build cap remains 220 MiB/25 s with a 96 MiB Node heap; its remote browser group cap remains 2 GiB/60 s. The Chrome renderer is forced single-process SwiftShader for diagnostic isolation and is not phone or normal-browser performance evidence. The snapshot manifest is self-pinned by the run workflow. No command, test, build, browser, or server was run while preparing these files.
