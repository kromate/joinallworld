# Remote coverage-probe runner (prepared; root review required)

This remote-only harness builds the isolated `coverage-probe-v1` viewer, runs three synthetic barycentric-fragment cases with Node's test runner, then asks Chrome/ANGLE SwiftShader to load the pinned male and female production bodies, appearance, wardrobe, and exact source-corner chart. The unit step uses the same 96 MiB Node heap, 220 MiB process-group RSS, and 25 second wall caps as the build. It records one coverage JSON report per family and takes no screenshots. The fixed caps and process cleanup are inherited from the reviewed GPU v8 diagnostic recipe; they are not application budgets or performance claims.

The workflow is intended for a single push to `codex/graphics-office-shell-coverage-v1`, after root reviews and publishes the complete snapshot/workflow. It does not change or dispatch any existing CI workflow. A successful browser run must have both family reports, exact source/hash guards, exact production-mask replay, shell-fragment versus clipping-area agreement, each fragment inside all clipping halfspaces and source-face bounds, pairwise non-overlap, no shader/runtime/console/HTTP errors, stable source hashes, and verified child cleanup. Canceled network requests are recorded; uncanceled failures fail the run.

Expected output is `remote-results/<run-id>/browser-artifacts/review-results.json`, with zero PNGs, plus the stage log, Chrome log, build receipt, and browser receipt. The uploaded artifact should be inspected before any source or visual-fix proposal.
