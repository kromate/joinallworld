# Neck complement domain audit

This is a parallel diagnostic copy of the frozen neck-complement candidate. It does not edit production sources or the original `neck-complement-v1` receipt. Its purpose is to separate the broad historical neck-cut residual from the narrower domain the candidate actually declares.

The independent audit starts from the full appearance source index, replays the body mask, classifies the three corner regions, and clips each masked triangle against the candidate's torso/neck eligibility and all four geometric halfspaces. It computes expected per-face and union areas without consulting the complement output, then compares the generated complement against that independent result. The earlier 274-face neck-cut accounting is retained unchanged and each such face has corner region labels plus per-plane removed area. Any source face omitted from the candidate domain remains listed with its exclusion reason; it is not treated as visually covered or accepted.

A matching domain proves only that the candidate emitted the domain it declared. The browser capture is needed to judge whether excluded mixed-region/arm fragments produce visible gaps, and neither this experiment nor its source-domain checks establish whole-aperture, motion, or garment-quality acceptance.
