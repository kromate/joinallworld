# Bounded remote domain-audit recipe

The dedicated branch workflow verifies a complete immutable source/asset snapshot and the local import closure before dependency installation. It bundles the matched actual-body viewer, runs the focused fragment and independent-domain synthetic tests, then launches the existing bounded headless Chrome/SwiftShader review only if both earlier stages pass. The browser captures the actual male and female office source/candidate pair, eight sampled pose witnesses, and matched still frames for root review. Browser process topology and memory are diagnostic only; this is not a mobile-performance result.

The first report preserves the broad legacy neck-cut residual and provides an independent region- and four-plane-qualified candidate domain. Every excluded legacy face includes source corner-region labels and per-plane areas. Candidate output must exactly match the independent domain IDs and area by face. A match is not whole-aperture or visual acceptance: root must inspect the captured pixels and excluded-face report.

Root owns branch publication and remote execution. This recipe has not been run yet.
