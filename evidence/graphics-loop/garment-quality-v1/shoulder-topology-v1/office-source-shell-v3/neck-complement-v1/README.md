# Neck-complement candidate (unrun)

The production office body mask leaves a measured neck-region residual outside the generated office top. This isolated candidate reconstructs that residual from clipped source-body faces and gives it the same body material and source-corner skinning path. It does not change the production mask, source wardrobe, renderer, or any shipped asset. Prior UV/radius candidates are preserved separately and were not accepted.

The integration fixture compares two separately loaded copies of the same production male or female office look. Both use the exact source-corner chart; one adds only the measured neck complement. Before rendering it checks source-mask/chart replay, exact source-face area closure, existing body/wardrobe/shader pins, complement size/draw count, and the custom-skin position equation at eight real sampled poses. Remote screenshots compare source versus complement at eight idle yaws plus hard reach, walk, and sit views for both families.

This is a diagnostic candidate, not a quality claim. The remote SwiftShader images must be reviewed for skin continuity, collar and shoulder coverage, material tint, and visible holes. They do not establish normal continuity, ordinary-browser cost, mobile performance, or production lifecycle safety. No local browser/build/test run or production edit has been performed for this candidate.
