# Global Admin1 publication contract

This extends the accepted capture/inspection/planning checkpoint `29998a5d`. Read ADMIN1-OPERATIONS.md first. Preserve existing products, primary checkout, Nigeria rendering branch, source caches and ledgers. The bounded product has been published locally, independently verified and browser-previewed; this is not external publication. No new downloads, dependencies or game imports are needed for cache-only reproduction.

`admin1-product-types.ts` is coordinator-owned and frozen for this wave. Output lives only under `.cache/world-build/output/admin1-foundation/`. The exact plan's raw canonical partition bytes and global index bytes are immutable; do not add newlines or reserialize them. Inspection bytes use the existing canonical report plus one LF, giving the accepted report hash. Other indexes and manifest use canonical JSON plus one LF. References carry exact path, SHA-256 and byte count, with paths `partitions/<hash>.json`, `indexes/<hash>.json`, `reports/<hash>.json`, `countries/<hash>.json`, `manifests/<hash>.json`.

The root manifest binds full source and parent source/directory identity, report, compact global index, every partition and every parent country. Parent country records conserve all 258 existing units: linked countries have a country index, seven missing source units have null indexes, and protected `legacy-ng` has null index and no geometry. For other admitted sources, every source row remains either geometry or an indexed source-reference exception. Unlinked/ambiguous rows have no country index but remain in the global index and matching null-parent partitions or exceptions. Manifest counters conserve the source denominator and geometry/exception partition.

Country indexes contain compact bindings plus actual source `name`, `type`, `type_en`, `gadm_level` and audited position/polygon counts. Missing labels are null, not invented. All original properties and full geometry remain in partition assets. Levels are source metadata, not an official hierarchy; Antarctica's two level-0 units remain explicit. Structural checks and topology status are separate. No topology or playability claim is introduced.

Publication regenerates the deterministic plan from exact verified cached sources and the hydrated parent directory, in a terminated worker under the 120-second/512 MiB gates. Transfer partition buffers rather than cloning large arrays; do not run synchronous full-source planning in the controller. Bind an existing hash-verified inspection report and compare regenerated report exactly before publication. All asset hashes, membership, paths, counts and output size are rechecked. Enforce actual aggregate tree bytes/entries/depth including retained partial files and collisions; reserve 100 MiB free disk plus all missing bytes, largest-asset temporary-write headroom and audit-terminal headroom. Pre-read and bound immutable collisions before hashing. Write assets first, verify existing collisions, and publish the manifest last. A killed/interrupted attempt preserves assets for verified reuse, never silently accepts a missing/corrupt asset. Durable hash-bound attempt evidence precedes the worker, terminal evidence is written before releasing the shared acquisition lock, and no attempt-history reset is allowed. Cache-only compilation has zero source network. Count lifetime attempts per immutable request and enforce the eight-attempt frozen cap. The publication audit uses hash-bound attempt records with a 1 MiB/128-entry tree limit and 8 KiB per-record bound; the output tree has its separate byte/entry/depth caps and symlinks are rejected. No SQLite publication database or 512 KiB ledger is used.

The implemented browser-safe reader and preview validate strict field sets, source URLs/releases, exact parent hash/selected country, hash-path-byte references, counts, ordered unique source keys/IDs/ordinals, protected Nigeria, partition membership and full original feature hashes before drawing. Unknown schema, corrupt responses and path escapes are rejected; bytes are hashed before fatal UTF-8 decoding. Loading a country fetches only the manifest and selected country index, not the global index/report/source or all geometry. A partition is fetched only on feature selection; per-asset bounds apply, stale requests are aborted, and the UI exposes structural-only status. The root manifest is pinned for the session; country changes clear stale geometry/context. Source holes and higher ordinates are preserved, and source-reference exceptions cannot be drawn as empty successful geometry. Preview requests are same-origin with bounded time and cache behavior.
