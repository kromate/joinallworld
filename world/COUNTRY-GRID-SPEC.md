# Frozen country-wide geographic denominator

This additive cache-only milestone declares every selected grid cell against one verified country outline. It does not acquire buildings/roads, compile geometry, replace existing fan-out or add a scheduler. Existing country identities, manifests, primary work and Nigeria are immutable. Senegal is the first actual country. Shared interfaces are country-grid-types.ts, owned by the coordinator.

## Pure compiler (worker A)

Own only country-grid.ts and country-grid.test.ts. Export validateCountryGridRequest(unknown):CountryGridRequest, compileCountryGrid(request:unknown,boundary:CountryGridBoundary):CountryGridProduct, geographicGridCell(level,column,row):GeographicGridCell, geographicGridOwner(position:Position,level):GeographicGridCell.

Strict schema/keys and finite safe limit integers; request id safe lowercase48, SHA64, country id bounded string, level integer 0..16. Limits may only lower frozen hard caps. Refuse NG/legacy-ng in request or node, mismatched country/directory identity, wrong provider/kind/outline, missing geometry or unbound source reference. Boundary pins have hash-addressed category-relative paths, exact sha/bytes and original part order, manifest SHA equals request hash. No I/O, network, clock or mutation. Boundary loader separately proves these raw-byte pins against source artifacts.

A globally aligned geographic lattice uses step=1/2**level degrees, columns=360*2**level, rows=180*2**level. Cell id `geo-grid-v1:l<level>:x<column>:y<row>`, integer coordinates, bounds calculated from exact dyadic arithmetic. Cell lists sort numeric column then numeric row (not lexical ID). Canonical owner: +180 maps to -180, half-open west/south-inclusive east/north-exclusive cells; +/-90 singular pole point maps longitude to -180 and row clamps at last/first. No Mercator, source coordinate changes or inventing heights. Owners are geographic keys, not a claim existing local fan-out packs use a global rule.

Geometry is the pinned SOURCE LONGITUDE CUT representation. Actual Natural Earth Fiji is cut at +/-180; Antarctic main ring includes an explicit stepped -90 polar edge. Preserve all coordinates/polygons/rings/holes. Validate 2D finite ranges, rings >=4 with exact closure and at least3 distinct vertices, positions/counts/nesting before processing. Refuse a nonpolar adjacent longitude jump >180 pending explicit source-cut normalization; do not silently interpret arbitrary wrapped rings as huge countries. Source planar selection is not spherical topology or official boundary validation.

Enumerate unique bbox candidate cells from each polygon's exterior extent, bounded before allocating. Select inclusive polygon-vs-closed-rectangle contact: polygon vertices inside cell; any polygon ring boundary crossing/touching any rectangle edge; cell corners inside exterior and outside strict holes. Boundary-only contact including hole edges stays selected; a cell wholly within a hole is excluded. Polygon membership is union, record exact contributing polygon indices. No epsilon padding or simplification of source coordinates; robust orientation/intersection predicates must avoid missing contacts. Source-cut +180/-180 edge contact belongs to the corresponding longitude-cut cells; when source touches a seam add the physically adjacent opposite-side seam boundary-contact candidate and polygon index. Singular-pole contacts do not claim distinct physical pole destinations; bottom/top-row cells still cover near-pole sectors and canonical pole ownership uses column0. BboxCandidates records all considered unique cells, selectedCells only contact candidates. Keep operation counter for every potentially unbounded geometry comparison and fail closed at its cap; no partial plan. Abort/resource isolation is publisher responsibility. Return source/pins/node, grid, counts and every cell state not-started; geometryCoverage not-acquired. Canonical JSON plus newline, SHA256 bytes; requestHash SHA of canonical validated request (no newline). Strict output cap before publication.

Focused tests: polygon spanning country extent, concave bbox omission, holes and edge/corner ties, multipolygon overlap unique cells/indices, exact dyadic IDs at several levels, deterministic order, seam-cut geometry both sides plus seam-neighbour contacts, singular north/south pole ownership and polar source-cut sectors, arbitrary seam-crossing rejection, changed pins/identity/Nigeria, malformed/count/operation/output caps and no input mutation.
