Accepted exact source `2597acb7892042cc0d2a3f32ad9fe48912679991`, remote run
[37903828130](https://github.com/kromate/joinallworld/actions/runs/37903828130):
457 tests, three policy checks and World TypeScript. All 22 retained diagnostics
are hashed in [index-shard-source-plan-acceptance.json](index-shard-source-plan-acceptance.json).
Negative v23 and v24 evidence remains in the isolated worktree evidence directory;
their configuration projection and raw SQLite fixture decoding failures were
repaired without relaxing validators. No passing subset was promoted.

`prepareCampaignIndexShardPlan(id, configuration, policy, options)` is a read-only
producer exported from `campaign.ts`. It requires an existing schema2 grid-query
campaign with its complete captured root/leaf denominator. It validates the
pinned inventory and grid plan, re-verifies every retained capture and builds
request/context descriptors from those verified source jobs. Completed subdivision
parents are excluded only through the existing complete-root graph verifier.
Equal request hashes may group contexts only when their raw paths and exact
expectations agree. Unique requests, contexts, attempts and all encoded bytes
retain their fixed bounds. Planning does not open index SQL, bind a campaign
index, enqueue jobs, acquire data or create an index root.

The policy preserves the original campaign retry allowance and namespace budget.
Source release/layers, unchanged V1 base binding, manifest and source configuration
must agree. The five global plan pins are derived from verified values. Physical
reservation headroom, 128,000-byte session frames and the final 512,000-byte audit
envelope are independent gates; a logical planner total cannot replace them.
The envelope estimate includes the actual snapshot-root wrapper and conservative
identity/pin lengths. Required observation pins describe prepared constraints;
actual durable observation history must still be reconstructed by later audits.

Options permit only `allowedRoot` and an original immutable `expectedHash` for
resume. The producer snapshots caller configuration/policy before source IO,
checks a 60-second bound, then rereads campaign/inventory/grid bindings and the
entire source-job projection before returning. Its source evidence is explicitly
`source-plan-snapshot`, `not-admitted`, and `not-compiled`. This is a point-in-time
receipt. A dispatcher must repeat preparation while holding the relevant leases;
mutable returned bytes are not privileged proof of campaign or index completion.

Tests use explicit synthetic zero-row captures, including missing-source-row and
corrupt-retained-byte refusal. The accepted suite also includes legacy actual
retained-capture/session/audit/recovery checks and cross-language plan/binding
recomputation. It does not prove real whole-country coverage or unattended global
throughput. Country foundation, audited features, explorable geometry and playable
destinations remain distinct denominators.

The fixed legacy SIGKILL modes now live in `index_admission_worker.py` under exact
`--crash reserved` and `--crash binding-published` arguments. Invalid cases refuse
before runtime setup. The redundant standalone crash file was removed from the
fixed source inventory. The accepted 45-file closure has rounded source allowance
884,736 bytes and control allowance 1,040,384 bytes, below the unchanged 1 MiB
ceiling. Existing tooling/binding pins remain immutable; incompatible old
namespaces refuse rather than migrating or refunding consumed charges.
