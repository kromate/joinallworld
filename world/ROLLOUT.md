A separate worktree protects simultaneous edits; a separate output directory and SQLite file protect build state. A future adapter resolves `legacy Nigeria` or `world pack` before loading a map. The eventual integration changes only the map/content reader boundary, adds a lazy hierarchical destination directory, and introduces explicit country/timezone metadata for new destinations. Missing/replaced features require aliases/tombstones and an explicit migration review. Overture IDs have stability commitments that vary by type, and split/merge mappings are not guaranteed; store an internal game ID plus release-qualified source references. ## Climate, terrain and photorealism

Use ERA5 for region-scale climate normals, selecting a documented baseline such as 1991–2020. Store grid resolution, temporal period, variables, units and processing version. Temperature, relative humidity, precipitation totals and wind speed have different aggregation rules. In particular, do not claim that relative humidity computed from monthly mean temperature/dewpoint equals mean hourly relative humidity, or that the magnitude of mean wind components equals mean wind speed. Compute derived variables before aggregation or clearly label the approximation. Start with pilot regions before scheduling a global multi-decade extraction. [ERA5 monthly product and variable definitions](https://cds.climate.copernicus.eu/datasets/reanalysis-era5-single-levels-monthly-means?tab=overview).

Climate means are not today's weather. Default to a labelled climate baseline; future simulated variation must be deterministic, spatially coherent and bounded by source distributions. Optional current weather stores provider product type, effective time, collection time, TTL and fallback mode. Monthly precipitation in millimetres must not be reused as instantaneous rain intensity. A collector operates on selected game cells, not each player's GPS. Paid commercial weather access is a separate configured service; the first pipeline is offline-capable and makes no weather purchase.

Photorealism has three independent gates: source rights, measured rendering cost, and fidelity. Real footprints with estimated heights are useful now. Exact facades/interiors need licensed reference data; AI-generated plausible textures remain labelled representations. Preserve a low-detail mesh on every device. Terrain ingestion must distinguish DSM from bare earth and convert vertical datums before mixing elevations with WGS84 ellipsoid frames. Antarctic holes in terrain coverage get explicit flat/unknown fallback. Snow/cold is sourced per region/season; Africa has wet tropical, dry desert, savanna, Mediterranean and highland conditions.

## Device and operating budgets

The first measured production device target should be a named low-end Android available to the team; emulation is not a physical-device FPS measurement. Before widening rollout, record CPU/GPU/frame time, peak resident memory, decoded geometry size, bytes to first scene and camera movement under latency/packet loss. Start with two content requests, 60 KB Brotli per tile, 90,000 total visible triangles, 40 total visible calls and approximately 50 MB automatic cache. Count all visible geometry and draw calls, including ground/props and overlays. Brotli estimates are not actual transferred bytes unless the server negotiates compression. Cache eviction/disposal and cancelled requests need soak tests. Disk cache failures must not prevent play from the network. User-selected offline downloads show measured total bytes and remain separate from authoritative gameplay writes.

For unattended local operation, run one GIS/compile worker at first. Bound each source download, job input, output, maximum attempts and run duration. Enforce free-disk reserve before large downloads; a CPU wall-time limit needs a worker process that can be terminated, not just a clock check between synchronous jobs. Cancel gracefully, stop claiming, finish/abandon the lease and leave resumable immutable outputs. Do not silently retry permanent validation errors forever. SQLite WAL is local disk; a multi-host fleet requires a different queue/storage coordination design.

An initial two-day run can have a two-day time budget; that does not guarantee whole-world detail. Measure source bytes/s, features/s, tiles/s, p95 job duration, failure rate and resulting download sizes on Accra, Nairobi, Cape Town, London, Antarctic and sparse/dateline samples. Use those measured rates and source-unit counts to forecast the continent batch. Never extrapolate a tiny city fixture into a global time guarantee.
