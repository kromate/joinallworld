## Reader lane

Own only `preview/settlement-reader.ts` and `preview/settlement-reader.test.ts`. Export class `SettlementReader` with constructor `(options: SettlementClientOptions)`, getter `snapshot: SettlementReaderSnapshot`, `clearCache():void`, and `load(manifestUrl:string, manifestHash:string, binding:SettlementBinding, signal?:AbortSignal):Promise<SettlementReadResult>`. Use root's frozen client types and existing browser-compatible settlement validators; no Node/compiler/publisher/GIS imports. Fixtures are synthetic temporary in-memory Responses, never actual ledgers or data.

Only same-origin exact `/world-output/selected-places/manifests/<lowercase64hash>.json` URLs without search/hash/credentials and matching supplied hash. Origin option must be an HTTP(S) origin. `redirect:'error'`; reject redirected/unexpected-origin response URL, bad HTTP status and non-JSON MIME. Stream bounded fatal-UTF8 JSON; inspect content length when supplied, cap manifest 256 KiB / country 512,000 decimal bytes, exact point ref SHA/length. Every raw payload must match its content SHA before parsing/caching; call validateSettlementManifest and validateSettlementCountryPoints. Source and parent source have independent pinned releases. Require exact expected parentManifestHash AND all seven parent SourceRecord fields equal binding.parentSource before any point fetch; selected country ID must appear. No report/other-country/raw-source request. Missing country returns no point request. If binding is exactly legacy-ng + legacy-ng provider, return protected with null manifest/country/points BEFORE any request; reject mismatched legacy/provider combinations. This is local protection, not a claim that source counts were fetched.

Raw-byte LRU max5 MiB and256 entries; optional smaller positive cacheBytes for testing/device tuning, never larger. Cache keys include absolute URL/content hash, retain only verified bytes, parse/validate anew on return; no exported mutable cache buffer. Lifetime downloadedBytes counts decoded body chunks observed, including wrong hash/partial failures. requestStarts counts admitted fetch starts. Snapshot changes update observer with copied counters; observer errors must not corrupt state. At most two active fetch/body/hash/validation operations; queued max32. Semaphore releases in finally, queue cancellation removes listeners/entries; already-aborted requests start nothing. Apply 25s total per load including queue waits. Fully cached loads start no requests and bypass occupied concurrency slots; requestStarts has no lifetime quota; clearCache does not reset lifetime traffic. Bound redirects/URLs/content length/read work; close/cancel rejected body streams. Stale callers reject on cancellation even if bytes/hash finished; never cache failed/aborted data or return late success. No automatic retries.

Meaningful tests: exact manifest+selected-country two requests, no report/eager other country; repeat no traffic; same manifest different country only that asset; protected zero requests; missing only manifest; expected-parent source/hash mismatch no point request; wrong hash/content length/oversize/MIME/HTTP/redirect/nonfinite/schema/point-envelope rejection; aborted active+queued calls release slots; measured concurrent peak<=2 and queue bound; LRU eviction/reload with small cap; cache parsed objects cannot be mutated to change a later return.

Literal copy: selected city/town reference points, not all settlements/houses/admin1 containment/playable destinations. Explicit source license/release and exception counts, selected country's rows, no timezone/population inference. No HTML insertion using source labels; textContent only. Match existing panel classes.

Load uses options.binding, options.activate, clears old markers/list/selection immediately, aborts preceding load, and uses generation+complete binding identity checks before drawing. Reader enforces limits; panel owns cancellation on reset/country change. Protected Nigeria local return requires no entered URL and shows no request made; missing shows explicit source gap. Any wrong hash/error clears old rows/markers and verified context. Reader persists verified cache across reset; lifetime traffic remains visible. Snapshot metrics text and data attributes `downloadedBytes`, `cachedBytes`, `requestStarts`, `inflightRequests`, `queuedRequests` on #settlementMetrics; callback downloaded receives positive deltas of observed decoded bodies, including failures. Binding changes must prevent stale UI/error/points. Source text does not promise authoritative containment.

Search within selected country's already-downloaded rows, case-insensitive labels/key without new requests; bounded page50 rows; stable scaleRank then sourceKey order, duplicate names preserve distinct IDs/coordinates. Previous/next/overview work without fetching. Place click shows exact source ID and coordinates and calls options.focus(point); overview calls options.draw(currentResult). At most50 place buttons; do not create one DOM node per global row. Reset clears search/list/source/selection, preserving manifest URL/hash inputs and updating counters; cache/accounting persist. No unbounded timers/continuous redraw. Independent browser checks replace mirrored DOM unit fixtures.

Validate finite WGS84 coordinates and finite four-number positive-size viewBox. No input mutation, source-coordinate snapping, geographic containment claims, new world frame or projection dependency. Boundary-inclusive frame visibility. Priority selected in-view point first, then scaleRank ascending and sourceKey lexical. Max256 markers; eligible counts all in-view rows, outsideView the rest, deferred=eligible-markers.length. Display culling is explicit and does not remove downloaded source rows. Original point and IDs retained. Meaningful tests cover limits/count conservation/stable ordering/selected preservation, unchanged input, exact polar/dateline projection and hostile coordinates/viewbox.
