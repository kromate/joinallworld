## Pure compiler

`compileSettlementProduct(input: SettlementBuildInput): CompiledSettlementProduct` in `settlement-compile.ts`. `settlement-compile.test.ts` owns isolated, labelled synthetic fixtures. No network/filesystem/time/random operations. Verify source and raw parent byte/SHA pins before parsing; fatal UTF-8 and finite JSON numbers, bounded FeatureCollections and properties. Source keys use literal uppercase NE_ID, canonical positive safe integer numbers or digit strings without leading zero; duplicates/missing/invalid keys fail globally rather than invent identities. Parent keys are uppercase NE_ID and join through `parent.source.id + ':' + sourceKey` references to the provided verified country nodes, never names/ISO or casing fallback. Require all parent features/country nodes bound exactly once, unique IDs and only legacy-ng protected; its node must retain provider legacy-ng, countryCode NG, missing outline. Literal parent ADM0_A3 determines candidates; multiple candidates make an explicit ambiguous source join. NGA must map solely to legacy-ng or fail protection invariants.

Every source feature yields one audit row, sorted lexically by canonical sourceKey with original ordinal and canonical complete-feature SHA-256 preserved. ID is `place:natural-earth:${encodeURIComponent(sourceKey)}`. Keep countryId legacy-ng on protected lineage, null on unlinked/ambiguous. Protected rows contain no coordinates in output. Validate exact two-ordinate Point longitude/latitude with finite values and WGS84 bounds; unsupported/malformed points become explicit pointIssue, never snapped or substituted from LATITUDE/LONGITUDE properties. Audit rows contain no coordinates; report validPoints counts raw valid geometry, independent of join/protection. Names come only from literal NAME, NAMEASCII, FEATURECLA and integer SCALERANK 0..10; preserve exact strings without trimming, require nonempty <=256 UTF-8 bytes, malformed labels become labelIssue. No timezone/population inference and no ADM1NAME relation. Emitted requires linked + both issue fields null. invalidRows counts either issue, overlaps join totals; sourceUnits equals linked+protected+unlinked+ambiguous. exceptionUnits = sourceUnits-emittedUnits.

Publish one compact `SettlementCountryPoints` object per non-Nigeria country with emitted points, rows sorted by sourceKey with exact original geometry and label fields. No Nigeria or unlinked/ambiguous point asset. Every parent country has a sorted manifest reference: available iff emittedUnits>0, protected iff legacy-ng (no points), otherwise missing (no points). sourceUnits/emittedUnits remain exact for each country; report missingCountries includes nonprotected countries with no emitted point. Representation is selected-source-point-geometry, never playable destinations. Report and country envelopes bind source/parent manifest; full pinned SourceRecords remain in manifest/report.

Canonical JSON sorted object keys + exactly one LF for every asset. Paths `reports/<sha>.json`, `points/<sha>.json`, `manifests/<sha>.json`; hashes cover actual LF bytes. `assets` includes each distinct referenced asset once and manifest last; `bytes` is their exact aggregate. All limits come from frozen types: 32 MiB source,16 MiB parent,100k source rows,1024 countries,3 MiB report,256 KiB manifest,**512,000 decimal bytes per country** (unchanged route cap),16 MiB logical output. Reject oversize rather than silently dropping/truncating places or widening caps. Retain explicit limitations of selection/cartographic country depiction/no admin1/buildings/navigation/playability.
