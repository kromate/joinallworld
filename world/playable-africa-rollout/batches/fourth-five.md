# Fourth starter source batch

This packet contains Gaborone in Botswana, Windhoek in Namibia, Harare in
Zimbabwe, Maputo in Mozambique and Luanda in Angola. It remains outside the
first release of Cameroon, Togo, Ghana, Kenya and Algeria. Production currently
has Nigeria only; these files do not change a country to open.

The serial source generator retained 992 OpenStreetMap building footprints and
474 road lines across five bounded central samples. Country land and airport
points use the same pinned source inventory as the previous batch. Building
silhouettes are approximate boxes and missing heights are explicit estimates.
Visitor services, prices and the Lagos flight links are authored game content.
There is no current flight schedule, weather or whole-city coverage claim.

Windhoek's airport candidate is Eros and Luanda's is Quatro de Fevereiro in the
pinned OurAirports data. Candidate selection does not establish current airport
operations, an official aviation reference point or an international airline
route. These names must retain that distinction during admission.

Each country's full cached-source check and the actual clean-CI tracked-source
step passed. Local Node, compiler and browser checks were deliberately deferred
while Integration owns the shared heavy stage. The rollout workflow discovers
the ten authored receipt identities, checks their pins and runs each isolated
city journey and strict compiler serially on Node 22.19 and 24. Its fresh exact
remote result is required before calling this batch source-accepted.

Further admission requires a separately reviewed registry/atlas adapter, actual
hosted travel and save receipts, affordable return home, unchanged download
budgets and browser checks. None of those are proved by the source packet.
The first-five production delivery remains the immediate priority.
