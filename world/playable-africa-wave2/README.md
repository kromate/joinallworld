# Second playable Africa starter wave

This separate follow-up contains Cotonou in Benin, Abidjan in Côte d’Ivoire, Dakar in Senegal, Cape Town in South Africa and Addis Ababa in Ethiopia. It builds on the first five-capital module factory at a4c14a1e. Do not include it in that frozen first release without its own source acceptance and Integration admission.

All five generated maps retain actual bounded central OpenStreetMap roads and building rings, sourced city points, cited airport points and clipped Natural Earth land. They contain 1,105 retained building footprints and 533 street segments. Rendering still uses approximate box silhouettes and estimated heights where source heights are missing. Central samples are about660metres across, not complete cities or countries. Airports can lie outside the sampled centre; map bounds include their real points. No actual airline schedule or live operating status is asserted.

The airport source receipts distinguish direct AIP evidence from Addis Ababa’s explicitly archival mirrored AIP fallback. The latter is not asserted current and needs later direct ECAA revalidation. Cotonou and Abidjan are city choices, not claims that they are each the country's constitutional or political capital. Cape Town is the legislative capital. Full administrative geometry remains separate from the synthetic starter play zone.

Visitor homes, meals, clinic/workshop/market/recreation/reflection and community services are fictional game venues. Regional weather and currency remain provisional game behavior; no real local climate, culture, faith, election or household identity is fabricated.

## Reproduce and verify

Run `python3 scripts/world/build-playable-africa-wave2.py --check` offline to check all generated asset pins. Regeneration without `--acquire` requires the accepted cached raw source bytes. Explicit `--acquire --city <id>` uses the first converter’s existing serial8MiB/45second request boundary and reserved two-attempt allowance; it does not reset an earlier ledger or retry an identical failed request. Raw data remains outside game output.

Run `NODE_OPTIONS=--max-old-space-size=256 node --experimental-strip-types scripts/world/verify-playable-destination.ts <id>` for each destination before moving to the next. The verifier runs opened-content/map contracts, actual airport placement/core bounds, finite bounded street/building decoration, then an isolated test-ID engine journey through exact flight fare, duplicate-departure refusal, inflight save/reload, airport arrival, visitor meal, busy departure refusal, visitor reload, reverse fare and duplicate-return refusal, and original Lagos home/plot/style preservation. Each of the five passed locally before the next source acquisition. This does not certify actual host receipts, GPU rendering, phone performance or production.

The dedicated Node22/24 remote audit repeats asset pins and each verifier, then checks strict TypeScript without assertion waivers. Integration must review the exact accepted source, regenerate its shared catalogue/loaders/routes, extend foreign source checking to the correct receipt, preserve Nigeria-only atlas/admin contracts, and pass the existing startup/download and host/client/browser gates.
